# Sample data — synthetic

All files here are **fictional and illustrative**: buyers and competitors are invented and marked “(synthetic)”,
links use `example.com/.org/.net`, and every metric is generated by `scripts/generate-sample-data.mjs` (seeded).

| File | Use |
|---|---|
| `sample-workspace.json` | Loaded on first visit; also a valid backup for `scripts/cli.mjs`. |
| `buyers-example.csv` | Data → Import → Dream buyers. List cells (`pains`, `tried`, `phrases`) are separated by `;`. |
| `competitor-posts-example.csv` | Data → Import → Competitor posts. Competitors are matched by name. |
| `post-metrics-example.csv` | Data → Import → Your post metrics. Matches existing posts by title, otherwise adds them as published. |

Required columns: buyers `name`; competitor posts `competitor`, `hook`; post metrics `title`. Dates: `YYYY-MM-DD` or `DD/MM/YYYY`.
